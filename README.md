# Service SMM Planer

Скрипт для автоматического планирования и публикации постов в социальных сетях: **ВКонтакте**, **Telegram** и **Одноклассники**. 

Управление контентом полностью реализовано через сервисы Google: расписание и параметры задаются в **Google Таблицах**, а текст самих постов подтягивается напрямую из **Google Документов**.

## Основные возможности

- **Автоматический постинг по расписанию:** Скрипт ежеминутно проверяет таблицу на наличие запланированных постов (с учетом московского времени).
- **Мультиплатформенность:** Поддержка публикации в Telegram (включая GIF), ВКонтакте и Одноклассники.
- **Поддержка медиа:** Возможность прикреплять картинки и анимации по URL.
- **Умный парсинг текста:** Автоматическое извлечение текста из Google Документов и его базовая типографическая обработка (замена дефисов на тире, правильные кавычки-«ёлочки»).
- **Мульти-аккаунты и доп. группы:** Возможность настроить отправку постов сразу в несколько каналов или групп ВК через системный лист настроек.
- **Автоматические отчеты:** Скрипт сам проставляет статус публикации (`posted` или `failed`) в Google Таблицу.

## Требования

- **Python 3.10+**
- Сервисный аккаунт Google Cloud с доступом к Google Sheets API и Google Docs API.
- Токены доступа для нужных социальных сетей.

## Установка и настройка

1. Клонируйте репозиторий и установите зависимости:
```bash
git clone <URL_вашего_репозитория>
cd Service_smm_planer
pip install -r requirements.txt
```

2. Настройка доступов (API Ключи)
```text
VK_TOKEN=ваш_токен_вк
VK_GROUP_ID=айди_основной_группы_вк_без_минуса

TELEGRAM_TOKEN=ваш_токен_бота_тг
TELEGRAM_CHANNEL_ID=@ваш_канал_или_chat_id

OK_APPLICATION_KEY=ваш_app_key_одноклассников
OK_ACCESS_TOKEN=ваш_access_token_одноклассников
```

3. Авторизация Google

Проекту требуется JSON-файл с ключами сервисного аккаунта Google для чтения таблиц и документов.\
Файл должен называться t-osprey-457618-g6-3f1c8cc61184.json (либо измените это имя в файле scr/sheets.py) и лежать в корне проекта.

## Структура Google Таблицы

### Основной лист (Лист 1)
Должен содержать заголовки:

- Статус публикации — Сюда бот пишет posted или failed.

- Дата — Формат ДД.ММ.ГГГГ (например, 25.12.2023).

- Время — Формат ЧЧ:ММ (например, 14:30).

- Ссылка на документ — Ссылка на Google Doc с текстом поста.

- Соцсеть — Название соцсети (вконтакте, телеграм или одноклассники).

- Фото URL — (Опционально) Прямая ссылка на картинку или GIF.

- Статус публикации доп. группы — (Опционально) Статус для постинга во второстепенные паблики.

### Системный лист (links)
На этом листе настраиваются целевые группы и каналы для рассылки.
Заголовки (строка 1):

телеграм — ID каналов (по одному в строке).

одноклассники — ID групп ОК.

вконтакте — ID групп ВК.

vk_token — Токен ВК, соответствующий указанной группе (позволяет постить в разные группы от разных аккаунтов).

## Запуск

Для старта планировщика просто запустите main.py:

```bash
python main.py
```
В консоли появится сообщение: Scheduler started — Ctrl-C to exit. После этого скрипт будет каждую минуту (в 00 секунд) проверять таблицу на наличие постов, время которых уже наступило, и публиковать их.
